## 5. Backend — Routes

### 5.1 Authentication (WF-01 to WF-04)

- [ ] `POST /auth/register` — validate input, bcrypt hash password, insert user, issue JWT, trigger welcome email
- [ ] `POST /auth/login` — look up user by email, bcrypt verify, issue access + refresh tokens
- [ ] `POST /auth/refresh` — validate refresh token, issue new access token
- [ ] `POST /auth/logout` — blacklist refresh token in MongoDB
- [ ] `POST /auth/forgot-password` — generate reset token, sha256 hash, store in `reset_tokens`, trigger n8n
- [ ] `POST /auth/reset-password` — verify token hash, update password, mark token used
- [ ] JWT `@jwt_required` decorator for all protected routes

### 5.2 User Profile

- [ ] `GET /users/me` — return authenticated user's profile
- [ ] `PUT /users/me` — update name and currency
- [ ] `DELETE /users/me` — delete account and all associated data (expenses, budgets, alerts)
- [ ] `GET /users/me/notifications` — return notification preferences object
- [ ] `PUT /users/me/notifications` — update opt-in/out per notification type

### 5.3 Receipt Upload & OCR (WF-05)

- [ ] `POST /receipts/upload` — accept `multipart/form-data` image
- [ ] Validate file type (JPEG/PNG only) and file size (max 10 MB)
- [ ] Upload image to Cloudinary via Python SDK, capture `receipt_url`
- [ ] Preprocess image with Pillow — grayscale, contrast boost, binary threshold
- [ ] Run Tesseract OCR — `pytesseract.image_to_string` with `--psm 6`, `lang=eng+msa`
- [ ] Regex parsing — extract amount, date, merchant name, line items from raw text
- [ ] Assign confidence score — `high` / `medium` / `low` based on fields extracted
- [ ] Category detection — keyword lookup against `CATEGORY_MAP` dictionary
- [ ] Cleanup temp file from disk on success and on failure

### 5.4 Expenses (WF-06)

- [ ] `GET /expenses` — list all expenses with filters (category, month, date range, pagination)
- [ ] `POST /expenses` — validate fields, insert document, trigger background budget check
- [ ] `GET /expenses/:id` — fetch single expense, enforce ownership check
- [ ] `PUT /expenses/:id` — update expense fields, enforce ownership check
- [ ] `DELETE /expenses/:id` — delete expense, enforce ownership check

### 5.5 Dashboard (WF-07)

- [ ] `GET /dashboard` — MongoDB aggregation for monthly category totals
- [ ] Compute `remaining_budget` from budget settings
- [ ] Fetch 10 most recent transactions
- [ ] Generate rule-based insight message (current vs. previous month comparison)
- [ ] Count unread alerts for notification badge

### 5.6 Reports (WF-08 & WF-09)

- [ ] `GET /reports/monthly` — category breakdown, daily trend aggregation, month-over-month comparison
- [ ] `GET /reports/monthly/export?format=csv` — generate CSV with Python `csv` module, stream response
- [ ] `GET /reports/monthly/export?format=pdf` — generate PDF with WeasyPrint or ReportLab, stream response

### 5.7 Budgets (WF-10)

- [ ] `GET /budgets` — return all budget settings with live `spent`, `remaining`, `status` per category
- [ ] `PUT /budgets` — update overall and per-category budget limits
- [ ] Background budget threshold check after every `POST /expenses`
- [ ] Trigger n8n `budget-alert` webhook when category reaches ≥ 80%
- [ ] Trigger n8n `budget-exceeded` webhook when category exceeds 100%
- [ ] Write alert document to `db.alerts` on each trigger

### 5.8 Categories & Internal

- [ ] `GET /categories` — return all categories with colour codes and icons
- [ ] `GET /internal/users/active` — internal endpoint for n8n monthly cron (secured by `INTERNAL_API_KEY`)
